Cómo instalar y usar

Genera letras caja huecas para instalar LED por dentro y exporta STL / 3MF.

Instalar en el celular

Android (Chrome): menú ⋮ → Instalar aplicación (o "Agregar a pantalla de inicio").

iPhone (Safari): botón Compartir → Agregar a inicio.

La primera vez necesita internet; después funciona sin conexión.

Cómo usar

  1. Escribe el texto y elige la tipografía.
  2. Ajusta altura, profundidad, pared y base con los deslizadores.
  3. Gira el modelo con el dedo; acerca con pellizco.
  4. Elige Formato (STL / 3MF) y descarga:
    • Cuerpo → imprímelo opaco.
    • Tapa → imprímela en translúcido.
  5. Palabra completa: activa la bandeja con pasos de cable.
  6. Una letra suelta: elígela en el desplegable y descarga su cuerpo/tapa.
