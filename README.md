# Generador de Letras LED 3D (PWA)

Genera letras caja huecas (para instalar tira LED por dentro) y exporta
STL y 3MF, listo para imprimir en BambuLab.

## Publicar en GitHub Pages  (repo en la RAÍZ del dominio)

1. En github.com crea un repositorio **público** llamado EXACTAMENTE:
       ntalex04.github.io
2. **Add file → Upload files** y sube TODO el contenido de este ZIP
   (incluye los ocultos `.nojekyll` y la carpeta `.well-known`):
   `index.html`, `manifest.webmanifest`, `sw.js`,
   `icon-64.png`, `icon-192.png`, `icon-512.png`,
   `.nojekyll`, `.well-known/assetlinks.json`
   → **Commit changes**.
3. **Settings → Pages** → Source: **Deploy from a branch**,
   rama **main**, carpeta **/(root)** → **Save**.
4. En 1–2 min tu app queda en:
       https://ntalex04.github.io/

## URL para pegar en PWABuilder

       https://ntalex04.github.io/

## Instalar como app en el celular

Abre esa URL y usa el botón **Instalar** (o el menú del navegador):
- Android (Chrome): menú ⋮ → **Instalar aplicación**.
- iPhone (Safari): **Compartir** → **Agregar a inicio**.
La 1ª vez necesita internet; luego funciona sin conexión.
